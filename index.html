Deck rclone

A personal backup configuration using rclone and restic to save and restore encrypted backups in the owner's Google Drive.

What it does

Backup files are encrypted on the owner's computer before upload. The utility uploads encrypted files, reads its backup repository, and downloads files when testing or performing a restore.

Why it requests Google Drive access

The backup configuration requests Google's drive.file permission, covering files created or opened through the app. It uses that access to maintain its dedicated backup repository.

Personal use

This configuration is operated by its owner. It does not offer public accounts or a public backup service.

Read the privacy policy for details about Google data, storage, and revoking access.
