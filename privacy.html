Deck rclone

Privacy policy

Effective October 20, 2026. This policy describes the owner's personal Deck rclone backup configuration.

Access and use

The utility requests Google Drive's drive.file permission. It accesses the files and metadata available under that permission to create, read, and verify its backup repository and restore backup files.

Storage and sharing

Backup contents are encrypted before upload. Google Drive stores the encrypted files and associated file metadata. The owner's computers retain the authorization credentials needed to run the backups. This configuration does not sell Google user data, use it for advertising, or share it with an external application operator.

Retention and deletion

The current cloud backup process adds backup data without automatically deleting earlier cloud backups. The owner controls retention and can delete the repository in Google Drive. Stopping the utility or revoking authorization does not delete previously uploaded files.

Revoking access and contact

The owner can revoke this app's access through Google Account connections. For questions, use the support contact shown on this app's Google authorization screen.

This website

These information pages contain no analytics, forms, or application code that collects Google account or backup data. The hosting provider may process ordinary web request information when serving the pages.
